## ממצאים שמחייבים פעולה לפני הפצה

1. **Claude Code, Cursor Agent ו־Grok Build:** תנאי ספק קנייניים. Claude Code מותקן בזמן הבנייה ממאגר npm הרשמי; Cursor ו־Grok אופציונליים וכבויים כברירת מחדל, ונבדקים לפי טביעת SHA-256 קבועה, ללא אישור אוטומטי להפצה מחדש. אין להפיץ תמונות Docker או ארכיונים המכילים את הבינאריים האלה בלי בירור הרשאה. הפצת קוד האפליקציה אינה מעניקה למקבל רישיון חדש לכלי הספק. המקבל נדרש להסדיר בעצמו התקנה וגישה בהתאם לתנאי הספק.
2. **תמונות Docker:** חבילות GPL/LGPL/MPL ומקורות של בינאריים מצריכים טיפול לפי רישיונותיהם. הודעות קיימות נאספו, אך לא נארזה חבילת מקור מלאה לכל מערכת ההפעלה ולכל קוד מוטמע. הבדיקה אינה אישור להפצת התמונות בשלמותן.
3. **AGPL:** יש לצרף LICENSE ו־NOTICE, לשמור קרדיטים, לציין שינויים ותאריך ולספק את המקור המתאים לגרסה המחולקת. בפריסה ברשת יש להציע מקור גם למשתמשי השירות. עדיין נדרשת כתובת מאגר מקור שלכם בעת הפרסום.
4. **תלויות בעלות רישיון מתירני:** MIT/BSD/ISC/Apache וכדומה מחייבים שמירת הודעות לפי הנוסח החל. טקסטים מקוריים שנמצאו נשמרים תחת frontend/public/legal/texts, לפי טביעת SHA256.
5. **רישיונות מוגבלים לקבצים/רכיבים:** MPL, LGPL, GPL, CC-BY ו־CC-BY-SA אינם מוחלפים ברישיון האפליקציה. התאמות או הפצה של החומרים האלה מחייבות בדיקה לפי הרישיון הספציפי.

## גבולות הבדיקה

זהו מיפוי טכני של ראיות רישוי זמינות, ולא התחייבות שאין כל בעיה משפטית. הוא אינו מפרק כל בינארי, אינו מכריע בתוקף חוזים ואינו מעניק הרשאה בשם ספק. אין לסמן את ההפצה כמאושרת ללא טיפול בממצאים לעיל.

חבילת עדכון הקוד אינה מכילה מסד נתונים, חשבונות או את ארכיון Cursor המקומי. גם בכך אין אישור להפיץ תמונות מוכנות או קבצים קנייניים בנפרד.

אריזת עדכון נבדקת מול טביעות קובצי הרישיון, הנעילה, דרישות Python וקובצי Dockerfile שנרשמו במלאי. שינוי בהם חוסם אריזה עד לעדכון בדיקת הרישיונות. טביעה אינה תחליף לבדיקה מחדש של הרכיבים שנוספו או הוחלפו.

הקבצים legal/audit-node.cjs, legal/audit-python.py ו־legal/audit-os.py אוספים מטא־נתונים וטקסטי הודעות. legal/build-notices.cjs מאחד את הממצאים ואת נוסחי הרישוי למלאי שניתן לעיון מתוך התוכנה. קובצי המקור שנאספו נשמרו ב־legal/raw לצורך ביקורת.
