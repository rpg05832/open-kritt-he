סריקת אבטחה — מה יקרה בהתקנה

1. התוכנה תותקן בתיקייה של המשתמש שלכם, בלי הרשאות מנהל.
2. בסוף ייפתח אשף בעברית שבודק את המחשב:
   • אם אין Docker Desktop, האשף מציע מנוע Docker מובנה (מומלץ): סביבת Linux קטנה של Windows (WSL),
     רק לתוכנה הזאת, בלי Docker Desktop ובלי מנוי. אפשר לבחור במקומו ב־Docker Desktop, והאשף יוריד
     את המתקין הרשמי ויבדוק את החתימה. Docker Desktop חינמי לשימוש אישי ולעסק קטן
     (פחות מ־250 עובדים וגם פחות מ־10 מיליון דולר הכנסה בשנה).
   • ברשת מסוננת (למשל נטפרי) האשף מזהה אם חסרה תעודת רשת או שכתובת חסומה, ומסביר מה לעשות.
     תעודה מתווספת רק באישורכם, ורק לרכיבי התוכנה. Windows לא משתנה.
3. האשף בונה את רכיבי התוכנה (20–60 דקות בפעם הראשונה) ופותח את התוכנה.
4. בתוכנה פותחים "חשבונות" ומחברים חשבון AI שלכם.

עדכון: מריצים קובץ התקנה חדש. הנתונים, החשבונות וההגדרות נשמרים.
הסרה: דרך "הוספה או הסרה של תוכניות" ב־Windows. תישאלו אם לשמור גיבוי של הנתונים.
